# MultiTrans

MultiTrans is a powerful Android application designed for polyglots, language learners, and anyone interested in the linguistic connections between different cultures. Unlike traditional translation apps that focus on one-to-one translation, MultiTrans allows you to translate from one language to multiple others simultaneously.

## How it Works

The app provides a dynamic interface where you can add multiple language fields. You can type into **any** of these fields, and the app will instantly translate your input into all other selected languages. 

This is particularly useful for:
* **Polyglots:** Compare how a single phrase is structured across multiple languages you already know.
* **Language Learners:** Study similarities and differences between related languages (e.g., Romance or Slavic languages) in real-time.
* **Quick Reference:** Get a broad overview of a term across various regions.

## Features

* **Multi-Way Translation:** Input text in any field to see updates across all others.
* **Re-orderable Languages:** Customize your view by dragging and re-ordering your preferred languages in the settings.
* **Smart Resource Management:** 
    * Dictionaries are downloaded on first use and cached locally.
    * To save space, models are automatically deleted when a language is unselected from your active list.
* **Integrated Text-to-Speech:** Listen to the pronunciation in any of the supported languages.
* **Extensive Language Support:** Uses Android's built-in ML Kit translation capabilities.
